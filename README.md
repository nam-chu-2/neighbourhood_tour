# Bells Corners Radio

A short tour of Bells Corners — the village on Ottawa's west end where I grew up — built
for six co-workers who know only the downtown core.

The whole site is one thing: an analog car radio. Bells Corners is strung along a single
road, and the tour is strung along a single frequency dial. Drag the dial with your
thumb. Between stations there is static; when the needle settles on a station it locks
in, and that place's broadcast fills the screen — what it is, what it meant to me, and
what it would be if you only knew downtown. Received stations stay lit on the dial, which
doubles as the route, the progress bar and the table of contents. The light travels from
predawn to neon as you move along the band. Receive them all and the tour signs off with
a card you can keep.

**Zero cost, no server, no accounts, no API keys.** It is a static page. After the first
load it works completely offline, and nothing about a visitor ever leaves their device —
no location, no identifiers, no analytics.

## Quickstart

```bash
npm install
npx playwright install chromium

npm run dev            # http://localhost:5173 — also prints a LAN URL for phones
npm run build && npm run preview   # production build, with the service worker
```

Open the LAN URL on a phone. This is a thumb-driven interface; the desktop view will not
tell you whether it feels right.

Offline behaviour only exists in the built app (`preview`), never in `dev`.

```bash
npm test               # Vitest: band maths, tuning, palette contrast, storage, keepsake
npm run test:e2e       # Playwright: tuning, keyboard, offline, reduced motion, axe, perf
npm run typecheck
npm run lint
```

## Making it yours

Everything a visitor reads or sees is in `src/content/` — see
[`src/content/README.md`](src/content/README.md) for what each field means.

- `broadcast.ts` — the stations: name, frequency, memory, downtown translation, visuals.
  Frequencies increase in the order the places occur along the road, at least 0.4 apart.
- `palette.ts` — the five colours the dial travels through.
- `media/` — your images. `noise.png` is generated by `npm run noise`; leave it be.

`npm test` is the authoring guardrail. It fails specifically on a duplicate id, an
out-of-order frequency, stations packed too closely, a missing `alt`, or a palette stop
that drops below 4.5:1 contrast.

## How it works

The band is a native scroll container, so momentum, deceleration and the rubber-band at
each end are the platform's rather than ours. One rAF-throttled listener writes two CSS
custom properties — `--tune` (where the needle is) and `--detune` (how far off-station) —
and the palette, the grain, the blur and the needle glow are pure CSS functions of those
two numbers. React re-renders only when a station locks in, never while you are dragging.

Sound is synthesised with the Web Audio API rather than shipped as files, is off until
you ask for it, and carries nothing the screen does not already say.

Progress is a short list of station ids in `localStorage`. That is the entire stored
state.

## Deploying

Push to `main`; `.github/workflows/pages.yml` builds and publishes to GitHub Pages. A
project-path build uses `VITE_BASE=/neighbourhood_tour/`. `npm run qr` writes a QR code
for the published URL — the fastest way to get six phones onto the same link.
